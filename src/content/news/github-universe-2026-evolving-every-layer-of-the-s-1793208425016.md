<html><body><p class="wp-block-paragraph">Our jobs as developers are changing. In a couple of years, we&rsquo;ve gone from writing every line of code to working with AI assistants to orchestrating fleets of agents. But the goal hasn&rsquo;t changed: ship completed software work. A feature, a bug fix, a security fix. Completed work, not more code, is the output that matters.</p>



<p class="wp-block-paragraph">Today at <a href="https://github.com/events/universe/recap?utm_source=gh-universe-blog-k2k&amp;utm_medium=blog&amp;utm_campaign=universe-2026">GitHub Universe</a>, we shared our vision for GitHub as the most comprehensive software delivery system in the world. We introduced products that bring that vision to life and showed how we&rsquo;re rebuilding the infrastructure underneath it.</p>



<h2 id="h-our-vision-from-idea-to-completed-software" class="wp-block-heading">Our vision: From idea to completed software</h2>



<p class="wp-block-paragraph">The <a href="https://commandline.microsoft.com/new-agentic-software-delivery-primitives/">SDLC is no longer a linear</a> path from planning to coding to testing to deployment. A code change, a request from a colleague, or a production metric can trigger work anywhere in the system. Most of us (and our agents) jump between different stages, depending on the task at hand. Developers set the direction, make decisions, and stay accountable for what ships. Agents implement and verify changes. And everything feeds into and out of a continuous learning machine that makes the next cycle better.</p>



<p class="wp-block-paragraph">This agentic software delivery system solves for three things:</p>



<ul class="wp-block-list">
<li><strong>Velocity:</strong> get from idea to completed software as quickly, efficiently, and cost-effectively as possible</li>



<li><strong>Intelligence:</strong> combine context across the platform with a continuous learning engine, so the system gets better as you use it</li>



<li><strong>Quality:</strong> make completed work secure by default and catch bugs before they ship</li>
</ul>



<p class="wp-block-paragraph">GitHub is built for developers and their agents. We&rsquo;re also making the underlying primitives available, so you can build your own bespoke solutions. You stay in control of the work, the tools, and the cost.</p>



<h2 id="h-new-features-and-products-that-move-the-work-forward" class="wp-block-heading">New features and products that move the work forward</h2>



<p class="wp-block-paragraph">Today at Universe, we showed some of the latest products and features in action, starting with the GitHub Copilot app.</p>



<h3 id="h-github-copilot-app-from-issue-to-merge-in-one-app" class="wp-block-heading">GitHub Copilot app: From issue to merge, in one app</h3>



<p class="wp-block-paragraph">The <a href="https://github.com/features/ai/github-app?utm_source=gh-universe-blog-app-feature&amp;utm_medium=blog&amp;utm_campaign=universe-2026">GitHub Copilot app</a> is designed from the ground up for agentic software delivery. It connects your agents and tools across projects, so you can direct the work without making every handoff. And it&rsquo;s for more than producing code: you can write specs, present design discussions, or analyze telemetry in one agent-first surface.</p>



<h3 id="h-copilot-fusion-multi-model-orchestration-at-its-finest" class="wp-block-heading">Copilot Fusion: Multi-model orchestration at its finest</h3>



<p class="wp-block-paragraph">Different tasks need different models. Developers shouldn&rsquo;t have to manage every model choice to get the right result at the right price. <a href="https://docs.github.com/copilot/concepts/models/copilot-fusion?utm_source=gh-universe-blog-fusion-docs&amp;utm_medium=blog&amp;utm_campaign=universe-2026">Copilot Fusion</a> evaluates what a task needs across reasoning, code generation, debugging, and tool use, then chooses how to execute across one or more models. In the Artificial Analysis Coding Agent Index, Fusion Max scored within two points of Opus 5.5 Max at half the cost and 40% less time per task.</p>



<h3 id="h-copilot-projects-give-copilot-a-goal" class="wp-block-heading">Copilot projects: Give Copilot a goal</h3>



<p class="wp-block-paragraph">Available natively in the GitHub Copilot app starting today, <a href="https://docs.github.com/copilot/how-tos/github-copilot-app/working-with-projects?utm_source=gh-universe-blog-projects-docs&amp;utm_medium=blog&amp;utm_campaign=universe-2026">Copilot projects</a> let you run agent work across multiple repos in fully managed, parallel sessions. You have one place to track progress, make decisions, and direct what happens next. That means you can spend less time managing execution and more time deciding what&rsquo;s worth building.</p>



<h3 id="h-session-continuity-keep-working-across-surfaces" class="wp-block-heading">Session continuity: Keep working across surfaces</h3>



<p class="wp-block-paragraph">Your work shouldn&rsquo;t restart when you switch devices or tools. <a href="https://docs.github.com/copilot/how-tos/copilot-on-github/use-copilot-agents/manage-and-track-agents?utm_source=gh-universe-blog-session-continuity-docs&amp;utm_medium=blog&amp;utm_campaign=universe-2026#continue-a-session-from-another-client">Session continuity</a> lets you start and follow the same cloud agent session across the GitHub app, VS Code, the CLI, and the web. Start from your phone at standup, steer it from VS Code at your desk, and check in on it from github.com at lunch. The agent keeps working in the cloud. Our multi-model harness that enables it is powerful, fast, and cost-efficient.</p>



<h3 id="h-copilot-automations-learning-from-the-results" class="wp-block-heading">Copilot automations: Learning from the results</h3>



<p class="wp-block-paragraph"><a href="https://docs.github.com/copilot/concepts/agent-capabilities/agent-powered-workflows-and-operations/about-automations?utm_source=gh-universe-blog-automations-docs&amp;utm_medium=blog&amp;utm_campaign=universe-2026">Copilot automations</a> let you create AI-powered workflows within your repo. They run in the cloud, and you can kick them off manually or set them up to respond to an event or run on a schedule. That lets you coordinate agents to handle tasks such as issue triage and code review. And now, automations can learn from their outcomes and propose improvements for you to review and approve. That&rsquo;s the learning engine in practice. Use the results of the completed work to make the next run better.</p>



<h3 id="h-copilot-code-review-max-a-deeper-look-at-what-ships" class="wp-block-heading">Copilot code review Max: A deeper look at what ships</h3>



<p class="wp-block-paragraph">More code means more pull requests and more demand for review. Moving faster only helps if we can maintain the quality of what ships. <a href="https://docs.github.com/copilot/concepts/agent-capabilities/agent-powered-workflows-and-operations/code-review?utm_source=gh-universe-blog-code-review-overview-docs&amp;utm_medium=blog&amp;utm_campaign=universe-2026">Copilot code review</a> surfaces meaningful, actionable bugs that developers need to catch. Today, we introduced Copilot code review Max, which posted the highest F1 score on ReviewBench for high-severity issues. Lite and Balanced keep everyday reviews fast; the new Max provides a deeper look when a change needs it.</p>

<p class="wp-block-paragraph">Starting today, GitHub Enterprise customers can use all Copilot features without buying a separate subscription. That includes GitHub Copilot app, code review, automations, and more. You pay for the AI credits you use.</p>



<p class="wp-block-paragraph">This is available through <a href="https://github.com/enterprise/contact?utm_source=gh-universe-blog-contact-sales-form&amp;utm_medium=blog&amp;utm_campaign=universe-2026">GitHub Sales</a> today, with self-serve coming soon. Existing Copilot Business and Copilot Enterprise customers can keep their current plans or move over when they&rsquo;re ready. GitHub also remains open and extensible. Keep using the tools your team depends on, including Cloudflare, Datadog, Figma, and more.</p>



<h2 id="h-our-continued-infrastructure-investments" class="wp-block-heading">Our continued infrastructure investments</h2>



<p class="wp-block-paragraph">All of this depends on a foundation that&rsquo;s fast, reliable, and built to scale. Agents are changing the volume and shape of software development. Adding capacity matters, but capacity alone won&rsquo;t get us there. We&rsquo;ve also had to change the architecture.</p>



<p class="wp-block-paragraph">So far this year, we&rsquo;ve added:</p>



<ul class="wp-block-list">
<li>4 million CPU cores</li>



<li>160 PB of high-speed storage</li>



<li>50 Tb/s network capacity</li>
</ul>



<p class="wp-block-paragraph">We&rsquo;re also migrating <a href="https://github.blog/engineering/architecture-optimization/the-bridge-to-agent-scale-git-infrastructure/?utm_source=gh-universe-blog-git-infra-blog&amp;utm_medium=blog&amp;utm_campaign=universe-2026">to a multi-region deployment in Azure</a>, while continuing to serve incredible levels of traffic from developers around the world. We expect to complete the migration early next year. Those investments give us more room to grow. The next step is building the systems that handle the work.</p>



<p class="wp-block-paragraph">We&rsquo;ve scaled Git for years as activity on GitHub has grown. The agentic era calls for a different ceiling on throughput and reliability. Three principles guide our new <a href="https://github.blog/engineering/architecture-optimization/building-git-infrastructure-for-agent-scale-development/?utm_source=gh-universe-blog-git-architecture-blog-1&amp;utm_medium=blog&amp;utm_campaign=universe-2026">Git architecture</a>: simplify the primitives, decouple storage from compute, and minimize coordination.</p>



<p class="wp-block-paragraph">Git&rsquo;s just one example of the work we&rsquo;re doing to scale the platform. We&rsquo;ve done a lot of work across GitHub&rsquo;s AI gateway, the harness, and much more.</p>

It&rsquo;s to solve problems we couldn&rsquo;t solve before.</p>



<p class="wp-block-paragraph">That&rsquo;s why we&rsquo;re connecting the full software delivery system, giving developers better ways to work with agents, and evolving the infrastructure for what comes next. And we&rsquo;re doing it on GitHub, where we can build together.</p>
